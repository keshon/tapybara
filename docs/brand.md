# Brand

Everything visual, and the two traps that are easy to reintroduce.

## The mark

A microphone on a capybara-brown disc. It is drawn in code rather than kept as
a source file, so the same nine lines produce the application icon, the
favicons, the social banner and the README banner at whatever size each needs.

The generator is a small script that renders at eight times the target size and
downsamples — a cheap way to get clean antialiasing out of a rasteriser with no
supersampling of its own. The application's own tray icons are separate and
generated at runtime by `TrayIconHost`, because they are three coloured dots
and shipping three files for that would be silly.

## Colours

Taken from the application, not chosen for the website.

| Token | Light | Dark | What it is |
|---|---|---|---|
| ground | `#FAF6F1` | `#17120E` | page background |
| surface | `#FFFFFF` | `#1F1913` | cards |
| text | `#1F1913` | `#F5EFE8` | body |
| muted | `#6E5D4D` | `#A6947F` | secondary text |
| accent | `#8A5A2B` | `#D2A272` | links, buttons, eyebrows |
| pill | `#17120E` | `#17120E` | the panel the indicator sits on |

The brown is the disc from the icon. The dark is the indicator. The red used
for the recording dot is `#FF4D4D` in the application, and it appears on the
site only inside screenshots — never as a decorative accent, because in the
application it means *recording* and nowhere else.

The tray icon's idle colour is chosen at runtime from the taskbar theme:
`#D2D2D7` on a dark taskbar, `#404046` on a light one. A single fixed value
made the icon invisible on one of them.

## Typography

The site uses Bricolage Grotesque for display, Source Sans 3 for body and
JetBrains Mono for code and labels.

The application uses **Segoe UI Variable** — `Text` for body, `Display` for
page titles — at the sizes Windows Settings uses: 14 px body, 12 px captions,
28 px page titles. WPF defaults to plain Segoe UI at 12 px, which is close
enough to look like a mistake rather than a choice when the two windows sit
side by side. Always declare a fallback: Windows 10 has no Segoe UI Variable
and drops silently to something else.

## Site assets

Generated by scripts, not hand-edited:

```
assets/icon-512.png              the mark, for the page header
assets/og-banner.png / .webp     1200×630 social preview
assets/readme-banner.webp        1600×420, the header of README.md
assets/favicon/                  ico + png set + apple-touch
assets/screens/                  real screenshots
```

### Two traps worth knowing

**The indicator screenshots are lossless WebP.** They are nearly flat dark
fields, and lossy WebP shifts that flat colour just enough that the image shows
up on the page as a visible rectangle against a background of supposedly the
same tone. The window screenshots stay lossy — they are busy, the artefacts do
not show, and the files are a third of the size.

**The indicator is captured on `#17120E`**, and every panel it is placed on —
the site, the social banner, the README banner — uses that exact value. Change
one and the other has to change with it, or the seam reappears.

### Taking the screenshots

The settings screenshots are the real window, captured live. The indicator
screenshots are taken by constructing `OverlayWindow` directly and passing it
level values as numbers, rather than by starting a real dictation: a picture
for a website is no reason to switch on somebody's microphone, and it also
gives a repeatable waveform instead of whatever the room happened to sound
like.
